ผมอยากได้ feature ใหม่ คิดไว้ว่าอาจจะเป็น menu ใหม่บน navbar
feature นี้เกิดจากว่าใน 1 สัปดาห์ Gold Shop ภายในเกมจะรีเซ็ททุกๆวันจันทร์ 05:00 am ซึ่ง Gold ที่ผู้เล่นได้รับแบบไม่เติมเพิ่ม (ได้จากคอนเท้นในเกมเท่านั้น) ส่วนใหญ่จะไม่เพียงพอต่อการเหมาร้าน ผมจึงคิด feature นี้ขึ้นมาเพื่อที่จะจัดการปัญหาตรงนั้น โดยจะมีหน้าให้ user เพิ่ม/ลบ/แก้ไข ของที่วางขายในร้าน ของกี่ชิ้นราคากี่ gold (ตามในเกม ซึ่งจะมีบางชิ้นที่ Unlimited ด้วยนะ) โดยในเกมจะแบ่งหลายหมวดหมู่ บางทีก็มีหมวดหมู่เพิ่ม (events) เช่น Growth, Kafra Shop เป็นต้น
จากนั้นเมื่อบันทึกและกลับมาหน้าหลัก user สามารถลองเลือกว่าสัปดาห์นั้นจะซื้ออะไรบ้าง ระบบก็จะแสดงของทั้งหมดที่จะซื้อ และของที่เหลืออยู่ในร้าน แยกกัน พร้อมทั้งยอด Gold ที่ต้องใช้
โดยนอกจากนั้น user ยังสามารถเพิ่ม gold เฉลี่ยที่ได้รับต่อวันหรือต่อสัปดาห์ได้ด้วย ถ้า user เพิ่มไว้ ระบบก็จะหักลบให้และแสดงให้เห็นว่าขาดเหลือกี่ Gold

- เบื้องต้นคิดว่าระบบจะคล้าย dailies เลย
- อยากให้มีหน้า template สำหรับ admin เหมือนของ dallies ด้วย
- มี sub feature คือระบบบันทึก gold - จะให้ user มากรอก gold รายวันและเก็บเป็น calendar เหมือนออมเงิน แต่ต่างจากออมเงินตรงที่เอาไว้ดูย้อนหลังได้ว่าเฉลี่ยแล้วได้สัปดาห์ละเท่าไหร่ (feature นี้เป็น advance ไม่อยากให้รก feature หลัก)
